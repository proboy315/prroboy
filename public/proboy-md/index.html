ProBoy-MD

An advanced WhatsApp automation bot developed by Shahan Ali.

ProBoy-MD is a futuristic WhatsApp bot developed by Shahan Ali.

It supports advanced automation, media processing, interactive games, and auto-reply scripts.

Feature categories

  • AI tools — chat, coding and image-related helpers, depending on the configured provider.
  • Media utilities — conversion and media commands, subject to service terms.
  • Textmaker — text effects.
  • Group administration — moderation commands with admin checks.
  • Developer tools — owner-restricted utilities. Not a guide to remote command execution.
  • Fun and general utilities.

How it is structured

Baileys opens a WhatsApp multi-device session. A handler checks the prefix, command name and permissions, then a command file replies. Reported files include index.js, proboy.js, commands/, database/ and settings/. Do not publish session files or tokens.

Safety

A partial audit flagged remote-execution paths, stored tokens, and privacy-sensitive commands such as camera or phone lookups. Those should be reviewed, restricted and not used to monitor anyone without consent. This page does not document how to exploit them.
