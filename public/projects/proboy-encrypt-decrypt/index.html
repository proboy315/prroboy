ProBoy Encrypt & Decrypt

An AES-256-GCM encryption suite with image steganography and a local history vault.

ProBoy Encrypt & Decrypt is an encryption suite designed to securely protect text messages.

It also supports embedding hidden secrets inside images through steganography.

Users can decrypt, edit, re-encrypt, and manage their local history vault.

Capabilities

  • AES-256-GCM text encryption
  • Image steganography
  • Message decryption
  • Edit and re-encrypt functionality
  • Local history vault

Technologies: AES-256-GCM, Steganography, Web Crypto, Privacy Tool
