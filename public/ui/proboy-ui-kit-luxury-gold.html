16 Do & don't, responsive, performance

      

        
✔ Karo
    
          
  • Ek screen par ek primary button.
    • 
          
  • Container = .glass card, controls = raised, main action = primary button.
    • 
          
  • Saare inputs ek jaise, saare buttons ek jaise — mix mat karo.
    • 
          
  • Status = rang + text + LED.
    • 
          
  • Table ko .tw mein lapeto.
    • 
          
  • Destructive action par confirm modal.
    • 
          
  • Real error message dikhao (command, hint, HTTP status).
    • 
          
  • Phone par touch target ≥ 40px.
    • 
        

        
✘ Mat karo
    
          
  • Card ke andar card ke andar card — nesting 2 level se zyada nahi.
    • 
          
  • Ek hi element par bahut saare effects ek saath.
    • 
          
  • Bahut chamkeele neon glow — glow sirf active/LED par.
    • 
          
  • Pure white (#fff) background — theme dark hai.
    • 
          
  • Bina asli kaam ke "success" toast.
    • 
          
  • Web-font / CDN / icon-font jodna (offline toot jata hai).
    • 
          
  • Light source badalna — roshni/shadow ki disha poore page par ek hi rakho.
    •

CheezRule

        
Viewport<meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover"> zaroori.
